## 2. Original Certification Findings
The previous read-only certification audit established that the production implementation was architecturally compliant (Lazy Async Resource Ownership + Transient Event Loops) but identified five test defects spanning three unit test files due to stale mocks and signatures.

## 3. Root Cause of Each Test Failure
- **Whisper Tests:** The execution mechanism was updated to pass keyword arguments (`model`, `device`, `compute_class`) to the transcription service, but the test mock's assertion only expected a single `TranscriptionRequest` object.
- **LLM Tests:** The execution mechanism wraps the provider's async generation using `asyncio.run()`, requiring the test fixture's `generate` method to accept the new `model` and `timeout_seconds` parameters, which were missing in the stale mock.
- **Facade Tests:** The updated `TargetDescription` assumes dictionary-like metadata retrieval, but the test injected a `Mock` object for the metadata property, which resulted in `mock.get()` returning another `Mock` rather than falling back to defaults.

## 4. Exact Test Files Modified
1. `backend/tests/unit/runtime/invocation/test_runtime_invocation_facade.py`
2. `backend/tests/unit/runtime/execution/mechanisms/test_llm_execution_mechanism.py`
3. `backend/tests/unit/transcription/test_whisper_execution_mechanism.py`

## 5. Exact Assertions Corrected
- **Facade Tests:** Replaced `reg.descriptor.metadata` assignment from a generic `Mock` to a real `{}` dictionary, enabling exact matching of `TargetDescription` defaults.
- **LLM Tests:** Updated `mock_generate` signature to `async def mock_generate(request, model=None, timeout_seconds=None)` to match the exact production interface.
- **Whisper Tests:** Updated `mock_service.transcribe.assert_called_once_with` to explicitly assert the exact propagation of `model`, `device`, and `compute_class` sourced from the `ExecutionTarget`.
