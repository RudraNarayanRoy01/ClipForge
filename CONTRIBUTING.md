# Contributing to ClipForge

Thank you for your interest in contributing to ClipForge! This document outlines our repository governance and contribution guidelines.

## Repository Governance

This repository strictly separates application logic from tooling, configuration, and documentation. All contributions must adhere to the existing conventions of the project without introducing unauthorized automation, CI pipelines, or unapproved runtime dependencies.

For detailed instructions on the contribution lifecycle, please read our [Contribution Workflow](docs/CONTRIBUTING_WORKFLOW.md).

## Getting Started

1. **Review the Architecture**: Familiarize yourself with the existing codebase and architecture documentation.
2. **Local Setup**: Follow instructions in [`docs/INSTALLATION.md`](docs/INSTALLATION.md) and [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md).
3. **Open an Issue**: Before starting work, ensure there is an open issue describing the bug or feature, using the provided issue templates.

## Code of Conduct

By participating in this project, you agree to maintain a respectful, inclusive, and professional environment for all contributors.
