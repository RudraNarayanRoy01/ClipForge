## 3. Architectural Decision
**Option D — Lazy Async Resource Ownership + Transient Event Loops**
The Execution Mechanisms will continue to use transient `asyncio.run()` loops to bridge to the Providers. However, the providers will decouple their internal asynchronous state from the global DI lifecycle.

## 4. R-001 Correction Plan (Cross-Loop Corruption)
- **OllamaProvider:** We will remove `httpx.AsyncClient` from its constructor. The provider will instantiate `async with httpx.AsyncClient(timeout=timeout) as client:` inside the `_do_generate` method, guaranteeing the socket is bound to the current transient loop.
- **WhisperTranscriptionService:** We will replace `asyncio.Lock` with `threading.Lock`. Because model loading requires blocking synchronization, we will wrap the lock acquisition and `WhisperModel` instantiation inside an `asyncio.to_thread` block to safely serialize cross-loop thread access.

## 5. R-002 Correction Plan (Timeout)
- **Ollama:** The `LLMExecutionMechanism` already successfully passes `timeout_seconds` down to the provider. The lazily instantiated `httpx.AsyncClient` will respect this timeout. If exceeded, a `TimeoutException` is translated to an `ExecutionOutcome.FAILED`.
- **Whisper:** The `WhisperExecutionMechanism` currently calls `t.join()` with no arguments. We will update this to `t.join(timeout=target.timeout_seconds)`. If the thread remains alive (`t.is_alive()`), the mechanism will immediately return `ExecutionOutcome.FAILED` with a timeout error message.

## 6. R-003 Partial Correction Plan (Cancellation)
- For Whisper, native thread cancellation is not possible without `process` isolation or C-level modifications. If a timeout occurs, the mechanism will abandon the thread (it remains orphaned in the background).
- Hard cancellation is explicitly deferred.

## 7. Ollama Resource Lifecycle
- **Creation:** `async with httpx.AsyncClient(...) as client:` inside `_do_generate`.
- **Destruction:** The context manager automatically closes the socket before the method returns.

## 8. Whisper Resource Lifecycle
- **Locking:** `threading.Lock()` provides thread-safe access to the singleton model instance across multiple transient mechanism threads.
