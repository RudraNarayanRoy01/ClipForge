## 3. Confirmed Deficiency
The investigation phase confirmed that global configuration (`AISettings`, `TranscriptionSettings`) is being passed directly via Dependency Injection into the concrete providers (`OllamaProvider`, `WhisperTranscriptionService`). This causes the providers to act as static runtime policy engines, independently owning decisions (model, device, compute type, and timeout) that architecturally belong to the Runtime. The Runtime currently receives pre-configured opaque providers, stripping it of its decision authority.

## 4. Target Architecture

**Before:**
```text
Environment -> AISettings/TranscriptionSettings
                      │
                      ▼
               Concrete Provider (reads model, device, timeout)
                      │
                      ▼
                 Runtime wrap (Mechanism)
                      │
                      ▼
                  Execution
```

**After:**
```text
Environment -> AISettings/TranscriptionSettings
                      │
                      ▼
     Runtime Composition (ProviderDescriptor metadata)
                      │
                      ▼
             TargetSelector (selects target)
                      │
                      ▼
       ExecutionTarget (carries model, device, timeout)
                      │
                      ▼
       ExecutionMechanism (extracts & passes kwargs)
                      │
                      ▼
     Concrete Provider (receives explicit execution kwargs)
```

## 5. Configuration Ownership Model
- **Provider**: Runtime (`RuntimePipeline`/`TargetSelector`)
- **Model**: Runtime (`TargetDescription` -> `ExecutionTarget`)
- **Device**: Runtime (`TargetDescription` -> `ExecutionTarget`)
- **Compute**: Runtime (`TargetDescription` -> `ExecutionTarget`)
- **Timeout**: Runtime (`TargetDescription` -> `ExecutionTarget`)
- **Retry**: DEFERRED to 6C.4 (Reliability Redesign). `ai_max_retries` remains untouched.
- **Provider-specific tuning** (e.g., `beam_size`, `host`): Concrete Provider Constructor

## 9. DI Changes
**intelligence_module.py:**
Remove `ai_settings` from `OllamaProvider`. Inject explicit provider-specific initialization.
**infrastructure_module.py:**
Remove `TranscriptionSettings` from `WhisperTranscriptionService`. Inject `beam_size` and `language`.
**runtime_module.py:**
Resolve `AISettings` and `TranscriptionSettings` to populate `ProviderDescriptor.metadata` during provider registry enumeration.

## 10. Provider Changes
**OllamaProvider:**
- Constructor signature: `def __init__(self, host: str, default_temperature: float, http_client: httpx.AsyncClient)`
- `_do_generate` signature: `async def _do_generate(self, request: AIRequest, **kwargs: Any) -> AIResponse`
- Logic: Extracts `model` and `timeout` from `kwargs`. Fallback to safe defaults if omitted.

**WhisperTranscriptionService:**
- Constructor signature: `def __init__(self, beam_size: int, default_language: str)`
- `transcribe` signature: `async def transcribe(self, request: TranscriptionRequest, **kwargs: Any) -> Transcript`
- Logic: Extracts `model`, `device`, `compute_class` from `kwargs`.
- Caching: Update `_ensure_model_loaded(model, device, compute_type)` to reload model ONLY if the requested parameters differ from the currently cached model instance.

## 11. Runtime Changes
**TargetSelector & RuntimeInvocationFacade:**
Transport `metadata["model"]`, `metadata["device"]`, `metadata["timeout_seconds"]`, `metadata["compute_class"]` from the `ProviderDescriptor` into `TargetDescription` and `ExecutionTarget`.

**Execution Mechanisms:**
`LLMExecutionMechanism` and `WhisperExecutionMechanism` extract fields from `ExecutionTarget` and append them as kwargs to the respective provider method invocations.

## 16. Scope Boundaries
**Explicitly NOT Implementing:**
- Hardware Discovery (Hardcoded/Configured mappings remain)

- Dynamic policy-based load balancing

## 17. Risk Matrix

| Risk                               | Probability | Impact | Mitigation |
| ---------------------------------- | ----------- | ------ | ---------- |
| Provider defaults lost             | Low         | Medium | Ensure `kwargs.get()` fallback or strictly provide configured defaults from Registry. |
| Runtime becomes provider-aware     | Low         | High   | Keep parameters generic (e.g., `model`, `device`, `timeout`) rather than SDK-specific constructs. |
| Application becomes provider-aware | None        | High   | Configuration stays abstract to Application, mapped via RuntimeModule. |
| 6C.2.3/6C.2.4 regression           | Low         | High   | Maintain pure Domain representations; errors explicitly re-raised as native exceptions. |
| Whisper model thrashing            | Medium      | High   | Add explicit state tracking (`self._current_model`, `self._current_device`) in `WhisperTranscriptionService` to only reload on drift. |
