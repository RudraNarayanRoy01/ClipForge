## 2. Investigation Baseline
- **Expected & Confirmed:** `milestone-6c-batch-6c.4.1-certified` (commit `29072a9`)

## 3. Confirmed Deficiency
The previously certified `ctranslate2==4.0.0` has no pre-compiled Python wheels for the current execution runtime (Python 3.14.6). This causes the `faster-whisper` installation to fail completely, which cascades into an `ImportError` during Whisper provider initialization, breaking the Runtime execution path.

## 4. Dependency Authority
- **Authority:** `backend/requirements.txt`
- **pyproject.toml:** Specifies `requires-python = ">=3.9"`, but delegates dependency declarations entirely to `requirements.txt`.

## 5. Python Version Decision
- **Authoritative Python:** The project specifies `Python >= 3.9`. The observed environment (Python 3.14.6) is the developer's implicit current environment, not a strict explicit requirement.
- **Decision:** Rather than forcing a Python downgrade which could destabilize the developer's broader OS environment, the dependency gap can be bridged transparently because a newer minor release of `ctranslate2` supports Python 3.14 natively while maintaining full compatibility with the certified `faster-whisper==1.0.3`.
