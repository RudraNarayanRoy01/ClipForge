## 2. Certification Blocker
The final certification audit identified a deterministic blocker: `TranscriptionWorkload` backward compatibility was incomplete. While instantiation with `request` was supported, attribute access to `.request` was removed, breaking existing callers (specifically `test_whisper_execution_mechanism.py`) with an `AttributeError`.

## 3. Root Cause
The 6C.3.1 implementation successfully introduced the `TranscriptionCapabilityContext` to encapsulate payload, but failed to provide an accessor property for legacy `.request` extraction on the `TranscriptionWorkload` object. 

## 4. Exact Correction Performed
A surgical correction was applied to `backend/src/transcription/execution/workload.py`. A `@property` named `request` was added to `TranscriptionWorkload` that explicitly proxies to `self.context.request`. 
This restores perfect backward compatibility without duplicating data or breaking the new Single Source of Truth architecture.
