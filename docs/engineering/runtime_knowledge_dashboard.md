## 6 Runtime Vocabulary Coverage

The following terminology is consistently applied throughout the Runtime Intelligence surface. Vocabulary is summarized only. There is no terminology drift, and vocabulary is never expanded:
- **Runtime:** The execution environment and systemic governance layer.
- **Capability:** An observable, governed functional ability exposed by the Runtime.
- **Service:** A defined unit of functionality managed within the Runtime boundary.
- **Contract:** A formal agreement specifying expected inputs, outputs, and behaviors.
- **Interface:** The observable boundary through which a Service or Capability is accessed.
- **Provider:** An entity responsible for fulfilling a specific Capability or Service.
- **Context:** The state and environmental information passed through the Runtime.
- **Policy:** A formal rule governing Runtime behavior, execution, or access.
- **Pipeline:** A defined sequence of Runtime operations or capabilities.
- **Lifecycle:** The governed stages of existence for a Runtime entity.
- **Governance:** The structured rules, authorities, and policies managing the Runtime ecosystem.
- **Runtime Truth:** The principle that every Runtime statement must be supported by approved evidence.
- **Runtime UNKNOWN:** The explicit designation for undocumented information.
