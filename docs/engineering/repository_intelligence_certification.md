- Repository Snapshot — Captures observable repository facts.
- Repository Inspection — Transforms repository facts into repository observations.
- Repository Quality Dashboard — Aggregates Repository Intelligence.
- Repository Identity Cards — Establishes canonical identities for Repository Intelligence artifacts.
- Repository Architecture Decision Records — Documents architectural decisions physically evidenced within the artifacts.
- Repository Technical Debt Register — Records technical debt objectively evidenced in the artifacts.
- Repository Runtime Health Report — Summarizes observable Repository Intelligence health.
- Repository Intelligence Certification — Certifies the completed Repository Intelligence subsystem.
