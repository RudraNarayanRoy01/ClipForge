# Architecture Decision Records (ADRs)

This directory contains the historical record of significant architectural decisions made during the development of ClipForge.

## What is an ADR?
An Architecture Decision Record is a short text file in a format similar to Alexandrian patterns that describes a set of forces and a single decision in response to those forces.

## Naming Convention
Files should be named `ADR-XXX-Title.md` where `XXX` is a sequential zero-padded integer.

## Status
Each ADR must have a status: `Proposed`, `Accepted`, `Deprecated`, or `Superseded`.
