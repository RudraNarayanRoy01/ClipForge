## 3. Production Composition Root
The real production composition root resides in:
- `backend/src/bootstrap/startup.py` (`initialize_container()` function)
- The global DI container is constructed by iterating over registered modules:
  - `InfrastructureModule`
  - `IntelligenceModule`
  - `CampaignModule`
  - `RuntimeModule`

## 4. DI / Container Architecture
The repository uses a custom lightweight Dependency Injection container implemented in `backend/src/infrastructure/di/container.py`.
- It supports Singleton, Transient, and Factory registration types.
- It automatically resolves constructor dependencies using Python type hints (`inspect.signature`).
- The application executes module registration to populate the `Container` instance before routing application requests.

## 5. Runtime Registration Inventory

- **RuntimeProviderRegistry:** Missing from production DI completely.
- **ExecutionEngine:** Registered as a Singleton in `RuntimeModule`.
- **ExecutionMechanismRegistry:** Registered as a Singleton in `RuntimeModule`.

## 6. Adapter Registration Inventory

## 7. Provider Registration Inventory

## 8. Mechanism Registration Inventory

## 9. Lifecycle / Scope Inventory
